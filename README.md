# Calldecca Operator

An app for managing Bland AI phone calls on your Mac.

**[Download the latest release](https://github.com/EvanKaminsky/Calldecca/releases/latest)**

Requires macOS 14 or later. One download supports Apple silicon and Intel Macs.

## Install

1. Download the ZIP from the latest release and unzip it.
2. Move **Calldecca Operator.app** into your Applications folder before opening it.
3. Open the app and enter the Bland API key provided by your team.

The app stores the key in your Mac's Keychain.

## Updates

The app offers automatic update checks.
You can also choose **Calldecca Operator → Check for Updates…** in the menu bar.
Your saved Bland key is retained when updating.

Downloads are published by Condecca, Inc. and notarized by Apple.
Updates are additionally signed for Sparkle. 
Release assets and the update feed are hosted here.
